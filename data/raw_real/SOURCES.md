## Complaints (1111) — `complaints_1111_province_type.csv`
- แหล่ง: data.go.th ชุด "จำนวนเรื่องร้องทุกข์ที่ประชาชนแจ้งเรื่องผ่าน 1111" (id `gdpublish-opm-0105-05-008`, สำนักงานปลัดสำนักนายกรัฐมนตรี, สัญญาอนุญาต Open Data Common) ดึงผ่าน CKAN API `datastore_search` เมื่อ 2026-10-06 (53,574 แถว, ม.ค. 2020 – มิ.ย. 2026)
- กรองเฉพาะ `Case_Objective = ร้องเรียน/ร้องทุกข์`, ตัดจังหวัด "ไม่ระบุจังหวัด"/"ต่างประเทศ", รวมจำนวนเป็นรายปี **ปฏิทิน** × จังหวัด × ประเภทปัญหาหลัก (7 ประเภท) — ปี 2020–2023 (ชุดนี้ไม่มีปี 2019)
- ตรวจแล้ว: 1,820 แถว ผลรวมรายปี 34,271 / 30,424 / 21,948 / 23,305 ตรงกับค่าที่คำนวณจาก API ต้นฉบับ
- ข้อจำกัด: มีเพียง 7 ประเภทปัญหาหลัก (กฎหมาย, กล่าวโทษเจ้าหน้าที่, การเมือง-การปกครอง, ทรัพยากรธรรมชาติและสิ่งแวดล้อม, พ.ร.บ.อำนวยความสะดวก, สังคมและสวัสดิการ, เศรษฐกิจ) ยังไม่ถูกจับคู่เข้า 6 ด้านของ BRD

## หมายเหตุการแมปข้อร้องเรียน 1111 → 6 ด้านตาม BRD
- ธรรมชาติและสิ่งแวดล้อม → ด้าน 4; เศรษฐกิจ + สังคมและสวัสดิการ → ด้าน 6;
  กฎหมาย + กล่าวโทษเจ้าหน้าที่ + การเมือง-การปกครอง + พ.ร.บ.อำนวยความสะดวก → ด้าน 5 (การแมปเป็นข้อสมมติของโครงการ)
- ครอบคลุมปี 2020–2023 (ปีปฏิทิน ใช้แทนปีงบประมาณ) ด้าน 4–6 เท่านั้น; จังหวัดที่ไม่มีแถวในช่วงนี้ = 0 เรื่อง
- ปี 2019 และด้าน 1–3 = ไม่มีข้อมูล (NaN) ไม่มีการประมาณค่า; คะแนน Mismatch จะถ่วงน้ำหนักใหม่จากตัวแปรที่มี
